# hamidspirit.github.io

this is my personal page: https://hamidspirit.github.io

plain HTML, CSS and JS, no build step. push to `main` and GitHub Pages serves it.

- `index.html` home: about, stack, a few projects, contacts
- `projects.html` all the projects
- `style.css` colors live at the top in `:root`
- `script.js` the dots-and-lines background and the card fade-in

the blog lives in its own repo ([Hamidspirit/blog](https://github.com/Hamidspirit/blog)) and is served at `/blog/`.

to preview locally:

```sh
python3 -m http.server
```

then open http://localhost:8000
